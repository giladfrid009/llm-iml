## Beaver 7B v1.0 Cost Model

These files were taken from the original `safe_rlhf` repository at: https://github.com/PKU-Alignment/safe-rlhf   
We only use the relevant files for the `PKU-Alignment/beaver-7b-v1.0-cost` model.

Note that there is no way to install the `safe_rlhf` package yet, and to avoid cloning the entire repository, we have copied the relevant files here.
